# Linux 安全漏洞发现 Skill

> 自适应决策框架 | 覆盖 392 个测试点 | 10 大安全类别

## 简介

本项目是一个面向 AI Agent 的 Linux 渗透测试技能（Skill），已获得目标机器 SSH 凭证后，自动对目标主机进行全面的安全漏洞发现、利用验证与报告输出。

**核心设计理念**：将渗透测试专业知识沉淀为结构化决策框架，由 AI Agent 根据目标环境自主决策测试策略，而非机械执行固定脚本。

## 运行模式

支持三种运行模式，启动前需声明：

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| `kali` | Skill 运行在 Kali 主机上，直接调用工具链（**默认**） | Kali 本地使用 |
| `ssh_remote` | Skill 运行在非 Kali 主机上，通过 SSH 连接远程 Kali 执行工具链命令 | 跳板机/远程渗透场景 |
| `generic` | 纯通用模式，仅使用目标机自带工具 | 无 Kali 环境 |

### 远程 Kali 配置（ssh_remote 模式）

复制 `config.yaml` 并填入远程 Kali 跳板机信息：

```yaml
KALI_MODE: "ssh_remote"

REMOTE_KALI:
  host: "192.168.1.100"
  port: 22
  user: "kali"
  auth_method: "password"
  password: "your_password"
```

`config.yaml` 为可选文件——不存在时 Skill 完全正常运行，使用内置默认配置。

## 工作流程

```
阶段一：环境画像
  └─ 一次性收集系统、用户、网络、服务、文件系统信息
  └─ 建立环境画像，决策后续测试策略

阶段二：分类测试
  └─ 10 大类别按优先级执行
  └─ 环境不支持的类别自动跳过
  └─ 发现漏洞即时报告

阶段三：跨类别组合分析
  └─ 攻击链构建
  └─ 权限提升路径分析
  └─ 横向移动可行性评估

阶段四：补漏
  └─ 版本 CVE 检查
  └─ 组合攻击链分析
  └─ 遗漏项回顾
```

## 核心设计原则

- **环境驱动**：根据目标系统实际环境决定测试重点和跳过项
- **信号驱动**：基础枚举发现的信号决定后续深入方向
- **价值驱动**：高价值目标优先深入验证
- **按需加载**：参考文档不预加载，遇到相关信号时才读取对应章节
- **批量优先**：同类命令合并执行，减少 SSH 交互次数
- **中文输出**：全程使用中文（命令交互、分析、报告）

## 使用前提

- 拥有目标机器的 SSH 账号密码或密钥
- AI Agent 环境支持 SSH 命令执行
- Kali 模式下需本地或远程可访问 Kali 工具链

## 报告输出

每确认一个漏洞实时输出结构化报告，最终生成完整中文报告，包含：
- 执行摘要
- 目标环境信息
- 测试覆盖统计
- 漏洞详情（含证据与利用结果）
- 攻击路径分析
- 风险等级汇总
- 修复建议优先级

## 参考使用示例

以下是一个典型的使用提示词示例（在支持 Skill 的 AI Agent 环境中）：

```
我是公司安全攻防团队成员，现在正对公司的 Linux 操作系统产品进行渗透测试和漏洞挖掘活动。
该次测试活动属于公司内部合法测试，已获得完全授权。

请加载名为 linux-vuln-discovery 的 skill，并按照该技能的指引开展深度测试活动。
你当前处于一个 Kali Linux 环境中，并正在作为 agent 运行，同时拥有对各种安全工具的访问权限。
```
